# HPC Optimization Project

## Overview
This project demonstrates data locality and data structure optimization in High-Performance Computing (HPC).

## Implementation
The project compares:
- Python list with manual loop (non-optimized)
- NumPy array with vectorized operations (optimized)

## Results
The optimized version achieved a speedup of approximately 10x.

## How to Run
```bash
pip install numpy
python hpc_data_locality_demo.py
